# Etch A Sketch

A simple Etch-a-Sketch drawing pad built with HTML/CSS/JavaScript.

Features
- Flexible N×N grid generated by JavaScript (default 16×16)
- Hover to draw (Draw, Random Color, Progressive Darken modes)
- Prompt to resize grid (max 100)

How to run
1. Open `index.html` in your browser (double-click or `start index.html`).
2. Use the `New Grid` button to enter a different grid size.

GitHub push
- Create a new repository on GitHub (e.g. `etch-a-sketch`).
- Add the remote and push:

```bash
git remote add origin <YOUR_REMOTE_URL>
git branch -M main
git push -u origin main
```

Note:
- The project uses a fixed drawing area of 960×960 pixels (see `styles.css`).
